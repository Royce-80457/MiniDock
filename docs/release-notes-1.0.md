MiniDock 1.0：macOS 菜单栏 Dock 再次点击最小化工具。

## 下载与安装

下载 **MiniDock-1.0-universal.dmg**，打开后将 app 拖到 Applications，再从应用程序启动。macOS 13+，同一 app 含 arm64 / x86_64。`SHA256SUMS.txt` 用于核对下载完整性。

**签名限制：本包使用 Apple Development 开发签名，尚未使用 Developer ID 分发签名或完成 Apple 公证。Gatekeeper 可能阻止互联网下载版本启动，不承诺开箱运行。** 仅确认来源可信后按 [Apple 官方说明](https://support.apple.com/102445)使用隐私与安全性里的系统允许入口；也可从源码自行构建。无需也不应关闭 Gatekeeper 或 SIP。

## 功能

- 前台应用 Dock 图标再次点击，尝试最小化当前普通窗口；后台激活、最小化后恢复保留原生路径。
- 菜单启用/暂停开关、实心/空心状态图标、复制日志。
- 紧凑的通用/排除应用设置，辅助功能入口、登录启动、应用图标列表与＋/−操作、圆形悬停帮助。
- 无网络代码、无遥测、无第三方 SDK；不修改 Dock 或系统动画偏好。

## 验证与已知限制

界面与悬停菜单已由用户实测确认；24 项核心规则测试、Release 构建和签名检查通过。DMG 的挂载与完整性验证结果见仓库验证记录。

部分应用/快速操作仍可能跳过增强或因无法确认最小化而暂停；这是保留的保护行为，版本号不代表所有应用已全面兼容。全屏、模态、不可最小化窗口跳过；多窗口、跨 Space、多屏、Intel 真机和旧 macOS 的完整交互验收仍未完成。

默认暂停。首次运行请在设置中授予辅助功能权限，再打开菜单“启用”开关；不兼容 app 可加入排除列表。
